English Summary (for reference)

Band Room Reservation AI (com.enezzang.yatte) is an AI chat app that checks real-time availability of rehearsal studios in Seoul and provides Naver Booking links with the date and time pre-selected. Bookings and payments are completed by the user directly on Naver; the app never books or pays on the user's behalf.

  • Data we collect: account info (email, name, password stored as a bcrypt hash) and API keys the user enters themselves (Google Gemini — required; Notion and YouTube — optional), which are stored encrypted in the developer's server database. The developer holds no LLM API key of their own.
  • Chat messages: relayed through the developer's backend to the Google Gemini API using the user's own Gemini key. Chat content is not stored on the server; conversation history is kept only on the device (DataStore) and is excluded from Android cloud backup and device transfer.
  • Third-party services: Google Gemini (AI responses, via the user's own key), Naver Booking (availability lookup only), Notion API (optional calendar logging), YouTube Data API (optional video search), and sheet-music sites (songsterr, mymusic5, ultimate-guitar — link search only). Personal data is never sold.
  • No ads, no analytics or tracking SDKs, no location collection, no in-app payments. The only Android permission the app requests is INTERNET — no location, camera, microphone, storage, or contacts access.
  • Reporting AI responses: inappropriate or harmful AI responses can be reported from the app's settings screen ("부적절한 AI 응답 신고"), which opens an email to the developer.
  • Retention and rights: account data is deleted upon account deletion or request; API keys can be removed instantly in the app's settings. Users may request access or deletion at cagameku3842@gmail.com.
  • Security: HTTPS in transit with additional payload encryption for sensitive requests (sign-in, sign-up, API key storage), bcrypt-hashed passwords, and encrypted storage of API keys.
